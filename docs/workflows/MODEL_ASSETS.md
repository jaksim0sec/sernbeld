# 모델 에셋·월드 제작

1. [아트 방향과 세계관](../../세른벨드_게임_컨셉_종합.md#2-아트-디렉션과-세계의-분위기), [기존 선례](../references/INDEX.md), [산출물 계약](../contracts/DELIVERABLES.md)을 확인한다. 생태는 환경, 분포, 우점종과 플레이어가 알아차리는 방식을 먼저 정한다. 이미지, 원본 모델, 적용된 런타임은 개별 상태로 기록한다.
2. 정적 월드의 미터 단위, Y 위, 배치 피벗을 사용한다. 기존 카엘 GLB는 런타임에 보정이 있는 선례라 새 에셋에 보정값을 복제하지 않는다. 설치·압축 형식은 [카엘 로더](../../src/gameplay/gameplay.part.js)의 `createCutstoneBridge`를 참조한다.
3. 루트 HTTP 서버에서 `/tools/dev/assets.html`을 열고 독립 GLB 또는 GLB.GZ를 교체한다. 사용 중인 Three/GLTFLoader, 조명, 1m 그리드에서 크기, 재질, 실루엣과 카메라를 검사한다. 충돌용 GLB가 있으면 겹쳐 비교한다. 범위 상자는 시각 확인용이다. LOD가 별도 GLB인 경우 같은 기준에서 차례로 연다.
4. 월드 배치 시 지역 소속과 스폰·접근·출입, 플레이어·NPC 동선, 상호작용 및 저장을 연결한다. 충돌 정책은 장식, 보행면, 차단물 중 의도를 명시한다. 카엘의 `box2`와 계단 정의를 사용해 실제 보이는 면과 충돌체를 맞춘다.
5. `node tools/verify.mjs world`에서 물리 엔진의 합성 시나리오와 카엘 실제 구조물을 모두 검증한다. 새 구조물은 어느 방향에서 접촉·통과해야 하는지 실제 위치를 포함한다. 3D 화면, 실제 동선, 충돌과 실기기 성능은 각각 검증 결과를 기록한다.
