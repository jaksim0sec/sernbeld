# 디버깅과 최적화

먼저 사용자 관찰을 구체적인 진입·위치·포즈·설정·입력 조건으로 재현한다. 관찰과 추정 원인을 구분한다. 물리 합성 테스트는 알고리즘을, [실월드 검증](../../tests/world-playability.mjs)은 카엘의 실제 지형·계단·벽과 모델 배치를 다룬다. 계단 접근·측벽 방향·카메라 레이·플레이어 접촉을 각각 확인한다. 충돌체 공통 코드와 누락된 개별 등록 중 확인된 원인에 맞춰 수정한다.

최적화 전에는 기준 SHA, 체형·품질·카메라, 화면 크기, 기기, 비교 경로를 기록한다. 외형의 비율·실루엣·얼굴·접합부·색·재질, 동작의 IK·이동·충돌·장착과 저장을 보존한다. 삼각형 수 및 GPU 버퍼 바이트, 프레임 시간, 초기 로딩 및 메모리 중 요청된 비용을 동일 조건에서 전후 비교한다. 자동 수치와 시각 결과를 함께 비교하고 실기기 수치의 측정 조건을 기록한다.

실패 시 첫 불일치 데이터와 경계를 좁힌 뒤 회귀 검증에 재현을 추가한다. 근거와 재현 조건은 [실패 사례](../knowledge/INDEX.md) 또는 기존 테스트 가까이에 남긴다.
