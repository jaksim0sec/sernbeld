# UI 작업과 실행 검증

[UI/UX 설계 지침](../UI_UX_DESIGN_GUIDELINES.md)의 A부터 진행한다. 목적, 필수 정보, 행동 경로, 중요도, 묶을 것과 계층을 정하고 [SEED](../../styles/seed.css)와 [캐릭터 생성 표준](../../src/entities/character/studio.html)을 본다. 시스템 관리 UI와 인게임 도구·마법진은 플레이 중 역할에 맞춘다.

- `/tools/dev/ui.html`은 실제 캐릭터 생성기 또는 게임을 지정한 프레임 크기로 띄운다. 게임은 현재 브라우저 저장 데이터를 쓰므로 테스트 중에는 별도 브라우저 컨텍스트 또는 로컬 서버의 별도 포트를 사용한다. 작업 중 HTML은 같은 저장소의 `tools/dev/` 아래 파일을 `fixture`로 넘겨 직접 띄울 수 있다.
- 기존 CSS와 실제 핸들러를 유지한다. 캐릭터 조작, 메뉴 이동 또는 스킬 장착처럼 핵심 행동을 정상 진입점에서 검증한다. 새 화면은 빈 상태, 일반 상태, 길거나 많은 데이터, 진입·닫기·복귀 및 오류가 있는 경우의 피드백을 본다.
- 모바일 세로와 가로에서 잘림·중복·여백·레이어·기존 제스처를 [지침 B](../UI_UX_DESIGN_GUIDELINES.md#b-검토-구현-후)와 비교한다. `node tools/verify.mjs browser`의 모바일·스킬·캐릭터 테스트와 실제 화면 캡처를 함께 사용한다.
