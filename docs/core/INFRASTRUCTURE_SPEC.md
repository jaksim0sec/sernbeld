# TRACE: 축적·계승형 개발 아키텍처

**TRACE (Task Routing & Agent Continuity Environment)**는 개발 지식의 지속적 축적과 작업 맥락의 독립적 계승을 위해 색인형 문서, AGENTS.md 지침 라우터, 표준 작업 기록 및 검증 체계를 통합하는 저장소 중심 개발 아키텍처다.

- 축적성: 확인된 기술 사실·실패 원인·승인 선례·계약·검증 근거를 해당 기준 문서에 남겨 다음 제작에 재사용한다.
- 계승성: 작업자나 세션이 바뀌어도 [작업 주소](../tasks/INDEX.md#작업-주소-규약), 기준 SHA, 진행 범위, 검증 결과와 다음 행동으로 작업을 복원한다.
- 구성: AGENTS.md는 진입 라우터, 색인형 docs는 지식의 원본, 작업 기록은 진행 상태의 원본, 검증 체계와 main은 결과 확정 기준이다. TRACE는 기존 인프라의 명칭과 운영 규약이며 별도 런타임이 아니다.

사용자가 요구한 것은 개별 결과물을 만드는 AI가 아니라 새 세션이 기존 성공·실패 지식을 자동으로 찾아 같은 품질과 계약으로 수백 개 콘텐츠를 생산하는 기반이다. 이 문서는 2026-11-24 요구와 1차 검수의 목적을 보존하며 구현 상세의 중복 원본이 아니다.

## 문제와 의도

- 의상 하나에도 표준 인체 추출, 뷰어 재제작, 조형 교정, 추출, 관절 호환과 등록이 반복됐다. 다른 에셋과 UI에서도 스타일·컨셉·검증 설명이 반복됐다. 사용자만 기본 오류를 찾아주는 구조를 제거한다.
- 세션 종료 때 계획, 승인 범위, 작업 상태와 기술 지식이 유실됐다. 여러 세션의 개발 결과가 별도 규격이면 통합 비용이 반복된다. Git을 공용 지식·산출물의 영속 기준으로 삼는다.
- 모든 미래 설계를 고정하지 않는다. 재사용 빈도와 변경 파급력이 높은 인터페이스부터 안정화하고, 합리적 중간 개편을 허용한다. 기존 정상 기능·원본·아트 방향을 보호한다.

## 완료 조건

1. [AGENTS](../../AGENTS.md)가 여러 분야의 현재 문서, 작업 흐름, 계약, 실제 구현·도구, 승인 선례와 실패 기록을 선택적으로 연결한다. 작은 작업에 전 과정 강제 금지.
2. 신규 제작의 입력·출력·등록·검증이 공통 규격을 따르며, 작업 시작부터 계획·구현·검증·실패 되먹임·문서 갱신까지 자율적으로 수행한다. 확인 가능한 불확실성은 직접 조사하고 중대한 미합의 결정만 질문한다.
3. [산출물 계약](../contracts/DELIVERABLES.md)과 [작업 기록](../tasks/INDEX.md)을 이용해 기획·시연·모델·의상·UI·NPC·아이템·스킬·건축의 구현/검증/승인 상태를 분리한다. 동일한 지식을 여러 파일에 복제하지 않는다.
4. [검증 정책](../validation/VALIDATION_POLICY.md)에 따라 데이터·호환·실제 기능·품질·통합을 구분한다. 실행 성공이나 정적 뷰어로 실제 품질을 대체하지 않는다. 사용자에게는 게임 방향과 미적 판단 등 필요한 승인만 요청한다.
5. 의상은 서로 다른 신규 형상과 남녀 리그의 어깨·팔꿈치·무릎, 실제 IK, 가림 및 레이어를 검증한다. 일반 3D는 실제 배치·충돌·LOD, UI는 실제 기능·계층·SEED를 검증한다. 임시 시편을 게임용 콘텐츠나 품질 승인으로 부르지 않는다.
6. 실전 제작 배치와 독립 세션의 재사용·병렬 통합으로 이전 대비 총비용을 측정한다. 3배는 목표이며 측정 전 성과가 아니다. 작업 수, 사용자 교정, 준비 반복, 회귀, 총 시간 및 가능한 토큰을 기록한다.

## 운영 원칙과 남은 증거

main에서 최신 SHA를 확인하고 변경 범위 충돌을 검사한다. 확인된 기술 사실·실패·승인 선례는 해당 기준 문서에 갱신한다. 과거 지침의 상황별 제약을 영구 금지로 오해하지 않는다. [지식 기록](../knowledge/INDEX.md)과 [INFRA-001](../tasks/active/INFRA-001.md)은 현재의 실제 근거와 미완성 범위를 관리한다. 최초 인프라 커밋 0eedd8b의 CI는 성공했으나 완전한 생산 파이프라인·실전 대량 제작·독립 세션 협업·실기기 검증은 별도 입증이 필요하다.
