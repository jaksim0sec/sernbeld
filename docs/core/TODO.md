# 세른벨드 전역 TODO

프로젝트 전체에서 아직 해야 할 일, 미완료 검증, 알려진 문제와 후속 개발 과제를 자연어 체크리스트로 관리한다. [현재 상태](CURRENT_STATE.md)는 구현 사실의 색인, [TRACE 작업 기록](../tasks/INDEX.md)은 개별 작업의 진행·범위·검증 원본이다. 이 문서는 다음 할 일을 찾는 전역 진입점이며 상세 계획이나 상태를 중복 관리하지 않는다.

## 운영 규칙

- 사용자가 요청한 작업을 우선한다. 완료 후 작업 여유가 있거나 다음 과제가 정해지지 않았을 때 이 문서를 확인한다. 여유 없이 종료하거나 작업 중일 때는 별도 착수를 강제하지 않는다.
- 위에서부터 우선 검토하되 최신 main, 작업 상세, 실제 검증 결과와 의존성·점유 범위를 확인한 후 지금 처리 가능한 항목을 선택한다. 진행 중인 다른 작업을 침범하지 않는다. 미합의 기능·디자인·비호환 변경은 제안으로 남기고 자의적으로 적용하지 않는다.
- 작업 도중 발견한 미해결 문제, 누락된 요구, 미완료 검증, 후속 과제는 종료 전 여기에 한 줄로 기록하거나 기존 항목에 연결한다. 중복 항목을 만들지 않는다. 장기·다단계 작업은 TRACE ID 및 상세 기록으로 연결한다.
- 각 항목은 실행할 일과 완료 판단 기준을 명시한다. 이미 해결된 항목은 최신 근거 확인 후 완료로 표시하거나 완료 기록으로 옮긴다. 부분 완료·실패·미실행을 완료로 처리하지 않는다. 과제 삭제나 우선순위 변경으로 미완료 요구를 숨기지 않는다.
- 우선순위는 잠정 운영 순서다. P1은 기존 기능·검증 안정화, P2는 확정 방향의 콘텐츠·품질 보강, P3은 여유 시간의 기반 개선이다. 사용자 지시가 우선한다.
