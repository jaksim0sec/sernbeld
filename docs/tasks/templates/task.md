# AREA-000 작업 제목

- 목표와 완료 기준
- 기준 브랜치와 시작 SHA
- 구현 단계 / 검증 범위 / 사용자 승인 범위
- 변경 경로와 보존 대상
- 계약, 의존 작업 ID, 병렬 변경과 충돌 가능 경로

| 요구/보존 기준 | 검증 명령 또는 방법 | 결과와 증거 |
| --- | --- | --- |

- 결정·남은 한계·다음 행동

## 반복 제작 비용을 측정할 때

요청부터 실제 게임 통합·검증까지 걸린 시간, 제작 환경 준비 횟수, 사용자 교정 횟수, 반복 문제, 통합 뒤 회귀, 사용 토큰(확인 가능하면)을 기록한다. 동일 유형·비슷한 난도의 이전 결과에서 같은 단위를 취하고 측정 불가 값은 비워 둔다. 예상 배율은 실측과 구분한다.
