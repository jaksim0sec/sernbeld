# MOTION-11261538 영상 재현 버그 원장 V01

상태: 항목별 상태 참조(관찰/사용자 보고 및 직접 검증). 이 문서는 해결 예정 결함과 검증 요구의 단일 상세 원장이다. [재사용 제작 원리](../../knowledge/MOTION_VIDEO_LESSONS.md)는 별개다. 기존 T1~T8에 배정하며 새 T를 늘리거나 현재 T2의 계측 작업을 폐기하지 않는다. 아래 배정/우선순위는 구현 범위에 맞춘 작업자 제안이며 사용자의 기존 요구를 축소하지 않는다.

## 개편과 평가의 관계 (2026-11-27 사용자 확정)

특히 T3는 이 원장을 중심으로 개별 버그 패치를 나열하여 진행하지 않는다. 기존 [T3 명세](MOTION-11261538.md#t3-지상-보행달리기후진회전점프착지-안정화)에 따라 T1의 공용 판정 기반과 T2의 모션·접촉·전환·제작 표준을 실제 기능에 적용하는 것이 먼저다. 원장의 사례는 개편 전 baseline과 개편 후 결과를 비교하는 평가 기준이다. 기존 T3 요구의 달성과 T1/T2 기반의 실제 적용을 별도로 검증하고, 해당 사례를 재현하여 남은 결함만 원인 중심으로 보완한다. 타 단계의 담당 범위, 보존 선례, 각 ID의 재현/검증 상세는 유지한다. 원장만 통과하거나 구조 테스트만 통과했다고 단계 전체를 완료 처리하지 않는다.
