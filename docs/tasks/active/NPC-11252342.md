# NPC-11252342 카엘 NPC 대화 콘텐츠 배치 통합

상태: DESIGNED / planned. T1~T4 미착수. 기준 a408a3d8ca7907c303699bb3a58cc3a3a1204e0c. 사용자 승인 범위: 외부 에이전트가 생산한 대화 템플릿을 받아 병합·검증하고 실제 콘텐츠 기준으로 키워드 재정의 및 자연성 검수 후 main에 반영. 이번 변경은 작업 계획 등록만 수행한다.

기준: [대화 계약](../../contracts/NPC_DIALOGUE.md), [콘텐츠 작성](../../workflows/LIVING_WORLD_CONTENT.md), [산출물 등록](../../contracts/DELIVERABLES.md), [검증 정책](../../validation/VALIDATION_POLICY.md), [현재 상태](../../core/CURRENT_STATE.md). 기존 NPC-003 엔진·생활 세계·서비스를 재사용한다. 승인되지 않은 세계관, 기능, NPC/아이템/사건 ID 및 경제 효과를 만들어 넣지 않는다.

## T1 외부 생산물 수집 및 배치 확정

- **새 세션에서 이 주소로 시작하면 첫 응답에서 사용자에게 다른 에이전트들이 만든 대화 템플릿 JSON/ZIP/파일을 제공해 달라고 요청한다.** 이미 해당 세션 또는 접근 가능한 프로젝트 파일에 원본이 제공됐으면 반복 요청하지 않는다.
- 템플릿을 받기 전에는 임의로 생산하거나 다음 단계로 넘어가지 않는다. 수신된 배치의 출처, ID 범위, named/personal/event 및 그룹 형식, 개수와 누락을 목록화한다. 생산 명세/키워드 파일이 있으면 함께 보존한다. 일부 배치만 받은 경우 실제 확보 범위를 명확히 하고 미수신 배치를 구분한다.
- 완료 기준: 사용자가 제공한 실제 원본 및 통합 대상 범위를 확인하고 원본별 수량·출처를 기록. 파일 부재는 대기 상태이지 완료가 아니다.

## T2 병합 및 규격 검증

- 수신 배치를 staging에서 통합한다. 동일 ID 및 의미 중복, topicId 충돌, node/slot/choice 참조, named NPC/직업/지역/태그/사건 fact 및 effect/service 참조를 최신 main의 실제 레지스트리와 대조한다.
- 현행 graph validator/registry로 전체 배치와 기존 콘텐츠를 함께 검증한다. 자동 순환·무조건 종료 경로·선택 조건·ok/fail/stale·지식 소유·그룹 참여를 검증한다. 범용·고유·사건 선정 우선순위와 기존 대화·서비스 보존을 확인한다. 미승인/미구현 기능 의존 템플릿은 제외 또는 보류로 분리하고 원본 출처를 유지한다.
- 완료 기준: 통합 후보 데이터와 통과/수정/보류 수량, 제외 사유, 실제 검사 근거 확보.

## T3 키워드 재정의 및 자연성 검수

- 중앙 통합 에이전트가 실제 카엘 주민/생활상/경제/사건/설정을 참조해 화제 키워드와 분류를 재정의한다. 키워드와 실제 template/topic ID의 매핑을 별도 기획 데이터로 관리하며, 계약에 없는 임의 필드를 그래프에 추가하지 않는다.
- 대화 전체 경로를 읽어 사용자 질문과 NPC 응답의 인과, 맥락 유지, 직업/성격별 말투, 반복, 친화도 및 사건 조건, NPC별 지식 차이, 자연스러운 종료/화제 복귀를 확인한다. 대화 선택지에 존재하지 않는 기능을 약속하지 않는다. 서로 다른 답변에 같은 무관한 반응을 하는 분기는 수정한다.
- 불필요한 전원 의뢰화, 설정 날조, 과도한 설명을 제거한다. 대사 의미를 바꾸는 새 설정은 보류한다. 수정 후 T2 검사를 다시 수행한다.
- 완료 기준: 키워드 매핑·자연성 검수 결과 및 수정/보류 근거, 최종 통합 후보 데이터. 자연성 판단은 사람이 검토 가능한 대화 경로 예시를 남긴다.

## T4 실제 콘텐츠 등록 및 최종 통합

- 최신 main 및 활성 작업 점유를 다시 확인한다. 기존 production 진입점과 계약에 맞춰 검수 완료 데이터만 등록하고 기존 선형 담화, 일반 서비스, 저장 상태를 유지한다. 병렬 작업과 겹치는 game.js/sw.js/runtime 등의 변경이 필요한 경우 점유 해제·범위 조정 후 작업하며 임의로 덮어쓰지 않는다.
- 실제 등록 배치에 대해 registry/resolver 및 대화·그룹·생활 세계 관련 회귀를 실행한다. 대표 named/personal/event 및 사용자 분기(종료/서비스/실패 포함)를 실제 게임에서 검증 가능한 범위까지 확인하고 필요한 번들/PWA·인프라 검사 및 최종 CI를 수행한다. 테스트 미실행을 PASS로 표시하지 않으며, 필수 실게임/실기기 검증은 같은 작업의 최종 게이트로 유지한다. 단순 CI 대기로 독립 작업을 막지 않는다.
- 카탈로그, 현재 상태, 작업 기록, 키워드 매핑과 실제 통합 수량/제외 내역을 갱신한다. 최신 main에 커밋하고 원격 반영 SHA를 확인한다. 실제 게임 콘텐츠 통합 완료와 잔여 검증 상태를 분리해서 보고한다.
- 완료 기준: 승인된 최종 템플릿이 실제 런타임에 등록되고 관련 필수 검증 증거와 원격 main SHA 확보.

## 진행 기록

- 계획만 등록. 외부 에이전트 생산물 미수신. T1 첫 행동은 템플릿 파일 요청이며 대사 생성·병합·게임 수정은 아직 하지 않는다.
