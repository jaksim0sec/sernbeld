## 목적/완료 기준
기존 SEED를 보존하며 참여성 대사 패널, 패널 외부 우측 상단 응답, 비참여성 말풍선, 기존 위치의 공용 접근 토큰을 실제 게임 진입점에 연결한다. 기존 거래/의뢰/인벤토리/저장 계약을 건드리지 않는다.
[설계와 실행 계획](../../superpowers/plans/2026-11-25-npc-dialogue-ui-v2.md), [계약](../../contracts/NPC_DIALOGUE.md).
대안: 기존 UI/후보/일과/액션을 재사용(채택), 신규 엔진 및 경제/저장 개편(제외). 디자인 결정: 제한된 청록 글래스와 이름의 모래색, 독립 선택지의 내용 맞춤 너비, 긴 데이터 스크롤. 별도의 카메라 전환 및 UI 전체 배경은 추가하지 않았다.

## 후속 통합 확인
- `de4a16e`의 원격 [검증 실행](https://github.com/jaksim0sec/sernbeld/actions/runs/45539219810)에서 NPC 단위 검증은 PASS, `world-performance`와 이를 불러오는 `foundation`은 NPC fixture의 `def.id` 누락으로 FAIL. 실제 주민 정의 계약에 맞게 테스트 fixture에 ID와 초기 `talkT`를 부여했다. 동일 소스와 테스트 본문을 JS 실행 환경에서 실행하여 수정 전 TypeError, 수정 후 PASS를 확인했다(시간 API 스텁 및 assert 어댑터 사용; Node 전체 실행과 구별).
- 위 원격 실행의 생태 GLB 재생성·셔츠 복구 검증 실패와 실월드 대화 검증/영속 NPC 자원 및 관계·기억 구현은 별도 미해결 범위다. 전체 통합 완료로 기록하지 않는다.
