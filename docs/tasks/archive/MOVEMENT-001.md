# MOVEMENT-001 달리기 스태미나

- 기준 `main`의 `5de4eac`. 요청 범위는 달리기 자원과 캐릭터 옆 원형 게이지다.
- 물리 60Hz 틱에서 이동한 지상 달리기에 초당 12.5를 소모한다. 최대 100, 0.8초 뒤 초당 25를 회복한다. 소진되면 걷기 속도로 내려가며 30 이상 회복하면 기존 입력으로 다시 달릴 수 있다. 스프린트 상태는 플레이어 런타임에서 관리한다.
- UI에서 필요한 정보는 잔량과 소진 상태다. 기존 Shift·터치 스틱 → 스태미나 소모 → 원형 게이지 순이며, 월드 앵커에 붙은 게임 HUD로 표시한다. 3인칭 허리 오른쪽, 1인칭 또는 카메라 압축 시 화면 중앙 오른쪽에 표시한다. 회복 완료 시 페이드아웃하며 탐험 화면에서만 활성화된다.
