# NPC-002: 데이터 및 행동 계약 후속 구현
기준: be309a3605889160f0954c85b8bc7f2f45242b7a
[실행 계획](../../superpowers/plans/2026-11-25-npc-dialogue-state.md). 기존 NPC-001 UI와 경제 동작을 보존한다. 실기기/전 게임 검증 결과는 별도 기록한다.

## 구현 및 확인 범위
- 안정 ID 기록을 Save v1에 가산하고 구형 지역 커서, met, 플레이어 재화/인벤토리 보존. 신규 경제 원장과 재고 초기값은 도입하지 않았다.
- 실제 Townsfolk 접근/대화 및 Society 선택지 실행에 연결. 거리, 이동 모드, 방향, 시야와 최신 도메인 조건을 검증하고 기존 행동의 성공/실패 결과를 저장한다. 활동 및 위치는 저장 시 관찰값으로 기록한다. UI 구조와 스타일 변경 없음.
- 테스트 RED/GREEN: 코어 API 미존재 및 기존 거리 이탈 후 후보 실행 실패를 재현하고, 데이터 계약/실제 클래스 추출/기존 대화 테스트를 JS 실행 환경에서 PASS 확인. 이 검증은 Node 전체 체크아웃 실행 또는 실월드 브라우저 검증이 아니다.
- 번들: 기준 6개 원본과 기존 game.js 정확 일치 확인 후 변경된 원본으로 재결합. PWA 캐시 버전 및 모듈 목록 갱신.
- 남은 범위: 실월드 대화/조작/모바일/저장 통합과 전체 CI, 경제의 NPC별 실제 소유권 및 NPC 간 관계·자율 활동은 별도. 독립 리뷰 도구 부재로 코드 자체 검토만 수행.
