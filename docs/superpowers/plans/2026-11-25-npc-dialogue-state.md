# NPC 데이터 및 행동 계약 후속 구현
> 실행: superpowers:executing-plans / test-driven-development. 사용자 요청에 따라 main에 직접 통합하며 별도 승인 턴 없음.
**목표:** 기존 대화/UI를 유지하고 NPC별 상태와 발화 선택 및 행동 판단을 데이터 경계로 분리한다.
**구조:** src/core/npc-dialogue.js는 저장 객체를 사용하는 안정 ID 상태와 발화·행동 조건을 관리한다. 기존 Townsfolk/Society에 연결하고 GameUI는 기존 표시/입력 계약을 유지한다.
**제약:** save.v1과 기존 met/regionEntities를 보존, 실제 경제 및 NPC 재고 소유권 이관은 병렬 경제 작업의 계약 범위 밖. 새로운 재화 초기값을 가정하지 않는다.
## 작업
- [x] 기존 NPC 테스트에 안정 ID 상태, 이전 커서의 최초 이관, 저장 왕복, 스냅샷 방어, 조건 재검증과 잘못된 선택 거부를 추가하고 RED 확인.
- [x] 코어 모듈 구현 및 GREEN; 기존 행동과 NPC 접근에 연결, 기존 첫 만남과 주변 발화 독립성 유지.
- [x] PWA 캐시와 소스/번들 동기화; 기존 테스트, 현재 main과 범위 재확인, 검증 결과 및 미검증 범위 문서화.
## 검토 초점
저장 교체/재로드, 오래된 커서가 새 상태를 덮는 문제, stale 선택/거리 변화, 빈 대사 풀, UI 변경 없이 기존 아이템 기능 보존. 브라우저 및 전체 CI는 별도 결과를 확인한다.

전체 CI/실월드 검증은 별도 결과가 필요하며 완료 선언과 구분한다.
