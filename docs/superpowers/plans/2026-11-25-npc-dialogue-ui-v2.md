# NPC 상호작용 UI v2 실행 계획 (2026-11-25)
기준 main 5e277bec917a79eda6b2acc81d08bc7aadf5d3e8. 사용자 합의: 참여성 대화 패널과 비참여성 월드 말풍선 분리, 응답은 패널 우측 상단의 독립 토큰, 기존 접근 레이아웃과 SEED 유지, 인게임 한정 색·절제된 글래스 허용.
- 대안: 기존 GameUI/Explore/Townsfolk/Society 유지하고 표시·세션만 수정(채택); 새 대화 엔진/경제/저장 재작성은 병렬 경제 작업과 충돌하므로 제외.
- 핵심/계층: 공용 접근 토큰(아이콘/이미지+콘텐츠명) → 명시적 참여 → 발화 패널(이름·직함·본문·종료) + 독립 응답 목록 → 기존 액션 → 후속 발화 또는 원상복귀. 주변 발화는 별도 일시적 이벤트로, 이동이나 저장에 영향 없음.
- 작업 1: 회귀 테스트를 먼저 추가하고 기존 구현에서 실패 확인.
- 작업 2: 기존 후보에 표시 유형/아이템 ID만 추가, 위치/도달 거리 유지. 공통 버튼은 안전한 DOM 텍스트 사용.
- 작업 3: 참여성 대화의 명시 종료, 중복 클릭 방지, 입력 차단과 기존 액션 연결; 주변 발화는 기존 NPC 일과/대사 풀에서 선택, 시간 제한·쿨다운, 첫 만남/저장 커서 불변.
- 작업 4: 기존 소스+번들 동시 변경, PWA 버전, 디자인 지침·현재 상태·카탈로그 기록, 최신 main 재확인 및 검증.
- 보존: 인벤토리/재화/의뢰/스킬/월드/저장 스키마, 기존 HUD 위치 및 아웃게임 스타일. NPC 소유 자원·관계·자율 의사결정은 향후 경제 계약에서 별도 구현.
- 검증: tests/npc-dialogue.mjs, 원본 번들 일치, 모바일 390×736/780×360/320×568, 기존 전체 검증 도구. 전체 런타임/실기기 검증이 안 되는 경우 명시한다.
